# NanyxCompiler.Cli

The `nanyx` executable: a small C# CLI over the compiler pipeline, implemented with Consolo.

## Usage

```
nanyx <run|wasm|check|parse> <file.nyx> [--out <path>]
nanyx <run|build> [<directory or .nyxpack>] [--out <path>]
```

- `run` compiles the file and executes it on the embedded Wasmtime engine. The program's output is the
  only thing written to stdout; diagnostics go to stderr. Exit code 0 on success, 1 for a compile or
  runtime failure, 2 for a usage error.
- `wasm` writes WebAssembly text next to the input (or to `--out`).
- `check` prints the compile phase, diagnostics and inferred types.
- `parse` prints the AST.

`nanyx hello` takes no file: it compiles and runs a "hello world" program built into the CLI, as a
quick check that the compiler and runtime work.

## Packages

Given a directory or a `.nyxpack` manifest instead of a file, or nothing at all, `run` and `build` work on
a package: the manifest in that directory (the current one by default) or the nearest directory above it.

- `build` checks every source file the manifest's `sources` select, with the analyzers its `[analyzers]`
  table turns on, and writes the program of the package's `@entry` to `out/<package name>.wat` beside the
  manifest (or to `--out`). A package without an `@entry` is only checked.
- `run` does the same checks, then runs the `@entry`.

A package runs only the analyzers its manifest names (`[analyzers.default]` for the official one); a file
run on its own runs every analyzer at its defaults. See `examples/greeter` for a working package.

The command-line entrypoint and help text are generated by Consolo from the command method in Program.cs.
